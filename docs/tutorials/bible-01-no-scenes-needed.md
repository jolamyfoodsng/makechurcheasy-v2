# Video 1: You don't need to build scenes in OBS

**Video file (no voice yet):** `bible-01-no-scenes-needed_silent.mp4` in this folder. **Length:** 1:41, 1920×1080.
**Voice:** slow and clear, one idea at a time. **Words:** very simple.

> **For the voice tool:** use a slow speed (about 85%). `...` is a short pause. Each line has a start time. If a line runs long, let it run into the quiet part right after it, never speed it up.

## How the app really works (tested)

- The app makes the **MCE Presentation** scene by itself.
- If you delete it, it disappears for about **1 second** and then **comes back by itself**. You do nothing.
- Needs a paid plan or trial. On the Free plan the app only gives a link.
